# Brewly ☕

AI-powered cafe discovery platform — find the right cafe using natural language search.

**Live demo:** https://brewly-cafe-finder.netlify.app

## Features
- Natural-language cafe search powered by Gemini
- AI Match % scoring with explanations
- Interactive map (OpenStreetMap)
- AI chat assistant ("Ask Brewly AI")
- Save favorites, filters, cafe details

## Tech Stack
React, TypeScript, Tailwind CSS, Google Gemini API, OpenStreetMap, Netlify

## Note
Currently running on sample/demo cafe data for showcase purposes.
